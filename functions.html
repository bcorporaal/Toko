Function Reference

An overview of some of the functionality in Toko. See the included example sketches for more details.

TokoWrapper

new TokoWrapper(options)

Creates a new TokoWrapper instance with the specified configuration options.

Parameters

  • {Object} [options={}] - Configuration options
    • {string} [options.title='untitled sketch'] - Title for the sketch
    • {boolean} [options.addInfoToTitle=false] - Append variant and render mode to the title
    • {string} [options.sketchElementId='sketch-canvas'] - ID of the canvas container element
    • {Object} [options.canvasSize=TokoWrapper.SIZE_DEFAULT] - Canvas size configuration
    • {string} [options.renderMode=TokoWrapper.RENDER_MODES.P2D] - Render mode (P2D, WEBGL, SVG, or WEBGPU)
    • {boolean} [options.shiftCanvasForWebGL=true] - Shift the origin to the top-left for WebGL (so coordinates match P2D)
    • {boolean} [options.useParameterPanel=true] - Enable parameter panel
    • {boolean} [options.hideParameterPanelOnStart=false] - Hide panel initially
    • {boolean} [options.showCanvasSizeOptions=false] - Show canvas size controls
    • {boolean} [options.showSaveSketchButton=false] - Show save button
    • {boolean} [options.saveSettingsWithSketch=false] - Save settings with sketch
    • {boolean} [options.acceptDroppedSettings=false] - Accept dropped settings files
    • {boolean} [options.acceptDroppedFiles=false] - Accept dropped image files
    • {boolean} [options.captureFrames=false] - Enable frame capture
    • {boolean} [options.showCaptureOptions=false] - Show capture controls in the panel
    • {Object} [options.captureOptions] - Capture configuration (see Capture System)
    • {boolean} [options.showFPS=false] - Show the FPS counter on start
    • {Array} [options.additionalCanvasSizes=[]] - Additional canvas size options
    • {string} [options.seedString=''] - Default seed string
    • {number} [options.debounceDelay=100] - Debounce delay for parameter changes
    • {boolean} [options.loggingEnabled=true] - Enable console logging
    • {string} [options.logLevel='info'] - Log level (error, warn, info, or debug)

Example

const wrapper = new TokoWrapper({
  title: 'My Sketch',
  canvasSize: TokoWrapper.SIZE_4K,
  useParameterPanel: true,
  showSaveSketchButton: true,
});

Canvas Size Constants

TokoWrapper provides predefined canvas sizes for common use cases:

TokoWrapper.SIZE_DEFAULT; // 800x800
TokoWrapper.SIZE_FULL; // Full window
TokoWrapper.SIZE_SQUARE_XL; // 1600x1600
TokoWrapper.SIZE_1080P; // 1920x1080
TokoWrapper.SIZE_1080P_PORTRAIT; // 1080x1920
TokoWrapper.SIZE_INSTAGRAM_PORTRAIT; // 1080x1350
TokoWrapper.SIZE_4K; // 3840x2160
TokoWrapper.SIZE_4K_PORTRAIT; // 2160x3840
TokoWrapper.SIZE_IPHONE_11_WALLPAPER; // 1436x3113
TokoWrapper.SIZE_WIDE_SCREEN; // 2560x1440
TokoWrapper.SIZE_MACBOOK_14_WALLPAPER; // 3024x1964
TokoWrapper.SIZE_MACBOOK_16_WALLPAPER; // 3072x1920

Render Mode Constants

TokoWrapper exposes render mode constants for use in the renderMode option:

TokoWrapper.RENDER_MODES.P2D; // 'p2d' - default 2D renderer
TokoWrapper.RENDER_MODES.WEBGL; // 'webgl' - 3D / GPU renderer (p5.js)
TokoWrapper.RENDER_MODES.WEBGPU; // 'webgpu' - GPU renderer (p5.js and Q5)
TokoWrapper.RENDER_MODES.SVG; // 'svg' - vector renderer (converted to P2D on Q5)

The render mode can also be set at runtime through the URL parameter ?r= (e.g. ?r=webgl, ?r=svg, ?r=webgpu).

Instance Properties & Methods

wrapper.renderMode

Read-only getter that resolves to the actual p5/Q5 renderer constant, so it can be passed straight into createCanvas().

Returns

  • {Object|string} - p5 renderer constant (P2D, WEBGL, SVG, WEBGPU) or the internal mode string if not yet available

wrapper.sketchElementId

Gets or sets the canvas container element id.

Returns

  • {string} - Current sketch element id

wrapper.storeCanvas(canvas)

Stores the p5/Q5 canvas instance so TokoWrapper can manage capture, drop, and save.

Parameters

  • {Object} canvas - Canvas returned by createCanvas()

wrapper.getCanvas()

Returns the stored canvas instance.

Returns

  • {Object} - Stored p5/Q5 canvas

wrapper.updateParameters()

Re-parses the parameter panel values and refreshes the sketch.

wrapper.saveSketch()

Saves the current canvas (png or svg, depending on render mode).

wrapper.saveSketchAndSettings()

Saves the canvas together with the current parameter settings.

Example

const wrapper = new TokoWrapper({ renderMode: TokoWrapper.RENDER_MODES.SVG });

function setup() {
  const p5Canvas = createCanvas(800, 800, wrapper.renderMode);
  p5Canvas.parent(wrapper.sketchElementId);
  wrapper.storeCanvas(p5Canvas);
}

wrapper.sketchElementId = 'my-canvas';
wrapper.updateParameters();
wrapper.saveSketch();
wrapper.saveSketchAndSettings();

Parameter Panel Integration

TokoWrapper integrates with Tweakpane. Define a global setupPanelControls(panel) function; TokoWrapper calls it with the panel object when the sketch starts.

panel.addPaletteSelector(paneRef, params, [options])

Adds collection and palette dropdowns (optionally with prev/next/random nav buttons).

Parameters

  • {Object} paneRef - Tweakpane tab or folder to add controls to
  • {Object} params - Parameter object that holds collection/palette values (and a collections list)
  • {Object} [options] - Selector options
    • {number} [options.index=1] - Insertion index for the controls
    • {boolean} [options.justPrimary=true] - Show only primary palettes
    • {boolean} [options.sorted=true] - Sort the palette list
    • {boolean} [options.navButtons=true] - Add previous/next/random buttons
    • {string} [options.collectionKey='collection'] - Key on params for the selected collection
    • {string} [options.paletteKey='palette'] - Key on params for the selected palette
    • {string} [options.collectionsListKey='collections'] - Key on params for the list of available collections

panel.addBlendModeSelector(paneRef, params, [options])

Adds a blend mode dropdown bound to a key on the parameter object.

Parameters

  • {Object} paneRef - Tweakpane tab or folder
  • {Object} params - Parameter object
  • {Object} [options] - Selector options
    • {string} options.blendModeKey - Key on params for the blend mode value
    • {boolean} [options.showAllModes=false] - Include additional CSS blend modes

panel.addEasingSelector(paneRef, params, options)

Adds easing type and direction dropdowns. Direction is hidden automatically for Linear and Smooth.

Parameters

  • {Object} paneRef - Tweakpane tab or folder
  • {Object} params - Parameter object
  • {Object} options - Selector options
    • {string} options.typeKey - Key on params for the easing type
    • {string} options.directionKey - Key on params for the easing direction

Example

function setupPanelControls(panel) {
  panel.primaryTab.addBinding(p, 'steps', { min: 2, max: 20 });
  panel.primaryTab.addBinding(p, 'rotation', { min: 0, max: TWO_PI });

  panel.addPaletteSelector(panel.primaryTab, p, {
    collectionKey: 'collection',
    paletteKey: 'palette',
    collectionsListKey: 'collections',
    sorted: true,
    navButtons: true,
  });

  panel.addBlendModeSelector(panel.primaryTab, p, {
    blendModeKey: 'blendMode',
  });

  panel.addEasingSelector(panel.primaryTab, p, {
    typeKey: 'easingType',
    directionKey: 'easingDirection',
  });
}

Capture System

TokoWrapper includes a capture system for recording videos and saving image sequences. Enable it with captureFrames: true and configure via captureOptions.

Parameters

  • {Object} [options.captureOptions] - Capture configuration
    • {string} [format='png'] - Output format: mp4, webm, png, jpg, gif, or webp
    • {number} [framerate=30] - Capture framerate: 15, 24, 25, 30, or 60
    • {number} [duration=100] - Number of frames to record when fixed
    • {boolean} [fixedDuration=false] - Record a fixed number of frames
    • {boolean} [refreshBeforeCapture=true] - Refresh the sketch before recording
    • {boolean} [recordButtonOnMainTab=true] - Place the record button on the main tab
    • {number} [bitrate=5000] - Video bitrate
    • {number} [quality=0.95] - Image/video quality (0–1)

Set showCaptureOptions: true to expose format, framerate, and duration controls in the parameter panel.

Example

const wrapper = new TokoWrapper({
  captureFrames: true,
  showCaptureOptions: true,
  captureOptions: {
    format: 'mp4',
    framerate: 30,
    duration: 300,
    fixedDuration: true,
    refreshBeforeCapture: true,
  },
});

File Handling

TokoWrapper supports drag-and-drop. Dropped JSON settings are applied automatically when acceptDroppedSettings is enabled. Other files are forwarded to a global receivedFile(file) callback when acceptDroppedFiles is enabled.

Parameters

  • {boolean} [options.acceptDroppedSettings=false] - Accept dropped .json settings files and import them into the parameter panel
  • {boolean} [options.acceptDroppedFiles=false] - Accept other dropped files and call receivedFile(file)

Callback

  • receivedFile(file) - Global function called for non-settings drops. The file object includes subtype (e.g. png, jpg) and data (file contents or data URL).

Example

const wrapper = new TokoWrapper({
  acceptDroppedSettings: true,
  acceptDroppedFiles: true,
});

function receivedFile(file) {
  if (file.subtype === 'png' || file.subtype === 'jpg' || file.subtype === 'jpeg') {
    loadImage(file.data, img => {
      // Use the image in your sketch
    });
  }
}

Save Functionality

Save controls can be added to the parameter panel, or invoked programmatically via wrapper.saveSketch() / wrapper.saveSketchAndSettings().

Parameters

  • {boolean} [options.showSaveSketchButton=false] - Show a save button in the parameter panel
  • {boolean} [options.saveSettingsWithSketch=false] - Also save parameter settings when using the panel save button

Example

const wrapper = new TokoWrapper({
  showSaveSketchButton: true,
  saveSettingsWithSketch: true,
});

// Or save programmatically
wrapper.saveSketch();
wrapper.saveSketchAndSettings();

Core Library

toko.getInfo()

Returns information about the toko library and detected p5.js variant.

Returns

  • {Object} Library information object
    • {string} name - The library name ("Toko")
    • {string} version - The library version
    • {string} variant - The detected p5.js variant (p5v1, p5v2, q5, or unknown)

Example

const info = toko.getInfo();
console.log(`Using ${info.name} v${info.version} with ${info.variant}`);
// Output: "Using Toko v1.1 with p5v2"

toko.detectVariant()

Detects the current p5.js variant.

Returns

  • {string} The detected p5.js variant (p5v1, p5v2, q5, or unknown)

Example

const variant = toko.detectVariant();
switch (variant) {
  case 'q5':
    console.log('Using q5.js');
    break;
  case 'p5v2':
    console.log('Using p5.js v2');
    break;
  case 'p5v1':
    console.log('Using p5.js v1');
    break;
  default:
    console.log('No supported library detected');
}

Random Functions

Toko provides additional random number functionality with seed control and shortcuts.

Seed Management

setSeed(seed)

Sets a specific seed for reproducible randomness.

Parameters

  • {string|number} seed - Seed value to use for random number generation

getSeed()

Returns the current seed value.

Returns

  • {string|number} - The current seed

randomSeed()

Generates a new random seed string.

Returns

  • {string} - A new random seed

resetSeed()

Resets the random number generator seed to restart the sequence from the beginning.

resetRNG([seed])

Resets the global RNG with a new seed.

Parameters

  • {string|number} [seed] - Optional seed value. If omitted, a random seed is generated.

nextSeed()

Advances to the next seed in the sequence.

Returns

  • {string} - The next seed value

previousSeed()

Goes back to the previous seed in the sequence.

Returns

  • {string} - The previous seed value

Example

// Set a specific seed for reproducible randomness
setSeed('mySeed');
const num1 = random(0, 100);
setSeed('mySeed');
const num2 = random(0, 100); // num1 === num2

// Get current seed
const currentSeed = getSeed();

// Generate a random seed
const newSeed = randomSeed();
setSeed(newSeed);

// Reset seed to restart the sequence
resetSeed();

// Reset the global RNG with a new (or random) seed
resetRNG('mySeed'); // pass a seed, or call without arguments for a random one

// Navigate through seed sequence
const next = nextSeed();
const prev = previousSeed();

Random Number Generation

random([min], [max])

Generates a random number.

Parameters

  • {number} [min=0] - Minimum value (inclusive)
  • {number} [max=1] - Maximum value (exclusive)

Returns

  • {number} - Random number between min and max

intRange(min, max)

Generates a random integer between min and max (inclusive).

Parameters

  • {number} min - Minimum value (inclusive)
  • {number} max - Maximum value (inclusive)

Returns

  • {number} - Random integer

randomBool()

Returns a random boolean value.

Returns

  • {boolean} - Random true or false

chance([probability])

Returns true with the given probability.

Parameters

  • {number} [probability=0.5] - Chance of returning true (0 to 1)

Returns

  • {boolean} - True with the given probability, otherwise false

steppedRandom(min, max, step)

Returns a random value from a stepped sequence.

Parameters

  • {number} min - Minimum value
  • {number} max - Maximum value
  • {number} step - Step size between values

Returns

  • {number} - Random value from the stepped sequence

Example

// Basic random numbers
const decimal = random(); // 0 to 1
const ranged = random(10, 20); // 10 to 20

// Random integers
const dice = intRange(1, 6); // 1 to 6
const index = intRange(0, array.length - 1);

// Random boolean
if (randomBool()) {
  console.log('Heads!');
}

// Probability check
if (chance(0.2)) {
  console.log('Rare event (20% chance)!');
}

// Stepped random numbers
const stepped = steppedRandom(0, 10, 2); // Returns 0, 2, 4, 6, 8, or 10

String and Character Generation

randomChar([chars])

Returns a random character.

Parameters

  • {string} [chars='abcdefghijklmnopqrstuvwxyz'] - String of characters to choose from

Returns

  • {string} - A single random character from the set

randomString(length, [chars])

Generates a random string of the specified length.

Parameters

  • {number} length - Length of the string to generate
  • {string} [chars='abcdefghijklmnopqrstuvwxyz'] - String of characters to choose from

Returns

  • {string} - Random string

Example

// Random characters
const letter = randomChar(); // Random lowercase letter
const digit = randomChar('0123456789'); // Random digit

// Random strings
const word = randomString(5); // Random 5-letter word
const password = randomString(8, 'abcdefghijklmnopqrstuvwxyz0123456789');

Array and Sequence Functions

shuffle(array)

Shuffles the elements of an array in place.

Parameters

  • {Array} array - Array to shuffle

intSequence(min, max)

Generates an array of integers from min to max in random order.

Parameters

  • {number} min - Minimum value (inclusive)
  • {number} max - Maximum value (inclusive)

Returns

  • {Array} - Array of integers in random order

random2DVector()

Generates a random 2D unit vector.

Returns

  • {p5.Vector} - Random unit vector

Example

// Shuffle arrays
const cards = ['A', 'K', 'Q', 'J'];
shuffle(cards); // Shuffles in place

// Random sequences
const sequence = intSequence(1, 5); // [3, 1, 5, 2, 4] (random order)

// Random vectors
const direction = random2DVector(); // Random 2D unit vector

Poisson Disk Sampling

poissonDisk(width, height, radius)

Generates evenly distributed points using Poisson disk sampling algorithm.

Parameters

  • {number} width - Width of the sampling area
  • {number} height - Height of the sampling area
  • {number} radius - Minimum distance between points

Returns

  • {Array} - Array of point objects with x and y properties

Example

// Generate evenly distributed points
const points = poissonDisk(400, 300, 20);
points.forEach(point => {
  circle(point.x, point.y, 5);
});

Color Palettes

p5.toko includes an extensive collection of curated color palettes.

Basic Usage

toko.getColorScale(name, [options])

Creates a color scale from a named palette.

Parameters

  • {string} name - Palette name (e.g., 'viridis', 'inferno')
  • {Object} [options] - Color scale options

Returns

  • {ColorScale} - Color scale object with methods for accessing colors

ColorScale methods

Methods

  • scale(t) - Get color at position t (0-1)
  • backgroundColor() - Get the background color for this palette
  • drawColor() - Get the drawing color for this palette

Example

// Get a color scale
const colors = toko.getColorScale('viridis', { steps: 10 });

// Use colors with scale function
fill(colors.scale(0.0)); // First color (at domain start)
fill(colors.scale(0.5)); // Middle color
fill(colors.scale(1.0)); // Last color (at domain end)

// Get background and draw colors
const bgColor = colors.backgroundColor();
const drawColor = colors.drawColor();

Create Custom Color Scale

toko.createColorScale(colors, [options], [extraColors])

Creates a custom color scale from an array of color values.

Parameters

  • {Array} colors - Array of color strings (hex, rgb, etc.)
  • {Object} [options] - Color scale options (same as getColorScale)
  • {Array} [extraColors] - Additional colors for contrast/background

Returns

  • {ColorScale} - Color scale object

Example

// Create scale from custom colors
const customColors = ['#ff0000', '#00ff00', '#0000ff'];
const scale = toko.createColorScale(customColors);

// Create scale with extra contrast colors
const extraColors = ['#ffffff', '#000000'];
const scaleWithContrast = toko.createColorScale(customColors, {}, extraColors);

Returns

const selection = toko.getPaletteSelection('viridis,inferno,magma');

// Get the list of available color interpolation modes (for Tweakpane)
const modes = toko.getColorModeList();

Color Options

The getColorScale() and createColorScale() functions accept an options object with the following properties:

Options

  • {number} [steps=5] - Number of color steps in the scale
  • {boolean} [reverse=false] - Reverse the palette order
  • {boolean} [sort=false] - Sort colors by brightness
  • {boolean} [constrainContrast=false] - Limit contrast between colors
  • {Array} [domain=[0, 1]] - Input domain for the scale
  • {string} [mode='oklab'] - Color space for interpolation (oklab, rgb, hsl, etc.)
  • {boolean} [useEasing=false] - Use easing for color interpolation
  • {Function} [easing] - Easing function for interpolation

Example

const colors = toko.getColorScale('viridis', {
  steps: 10, // Number of color steps
  reverse: false, // Reverse the palette
  sort: false, // Sort colors by brightness
  constrainContrast: false, // Limit contrast
  domain: [0, 1], // Input domain
  mode: 'oklab', // Color space (oklab, rgb, hsl, etc.)
  useEasing: false, // Use easing for color interpolation
  easing: toko.easeInOutQuad, // Easing function
});

Utility Classes

Grid

new toko.Grid(x, y, width, height)

Creates a new grid.

Parameters

  • {number} x - X position of the grid
  • {number} y - Y position of the grid
  • {number} width - Width of the grid
  • {number} height - Height of the grid

grid.setBaseGrid(cols, rows)

Sets a base grid structure with the specified number of columns and rows.

Parameters

  • {number} cols - Number of columns
  • {number} rows - Number of rows

grid.splitRecursive(depth, ratio, maxDepth, splitMethod)

Recursively splits the grid cells.

Parameters

  • {number} depth - Split depth
  • {number} ratio - Split ratio (0-1)
  • {number} maxDepth - Maximum recursion depth
  • {string} splitMethod - Split method constant (e.g., toko.Grid.SPLIT_LONGEST)

grid.gatherPoints()

Gathers all unique corner points from the grid cells.

Returns

  • {Array} - Array of point objects with x and y properties

grid.packGrid(width, height, cellShapes, shuffle, rotate)

Packs the grid with cells of different shapes.

Parameters

  • {number} width - Total width to pack
  • {number} height - Total height to pack
  • {Array} cellShapes - Array of shape definitions as [width, height]
  • {boolean} shuffle - Whether to shuffle cell shapes
  • {boolean} rotate - Whether to allow rotation of cells

Properties:

  • grid.cells - Array of cell objects with x, y, width, height

Split Method Constants:

  • toko.Grid.SPLIT_LONGEST - Split along the longest side
  • toko.Grid.SPLIT_HORIZONTAL - Always split horizontally
  • toko.Grid.SPLIT_VERTICAL - Always split vertically
  • toko.Grid.SPLIT_RANDOM - Split along a random axis

Example

// Create a grid
const grid = new toko.Grid(0, 0, width, height);

// Set base grid structure
grid.setBaseGrid(10, 10); // 10 columns, 10 rows

// Split recursively
grid.splitRecursive(3, 0.5, 10, toko.Grid.SPLIT_LONGEST);

// Access grid cells
const cells = grid.cells;
cells.forEach(cell => {
  fill(random(255));
  rect(cell.x, cell.y, cell.width, cell.height);
});

// Gather all unique corner points
const points = grid.gatherPoints();
points.forEach(point => {
  circle(point.x, point.y, 5);
});

// Pack grid with different cell shapes
const cellShapes = [
  [1, 1],
  [2, 1],
  [1, 2],
  [2, 2],
];
grid.packGrid(20, 20, cellShapes, true, true);

// Create noise instance with seed (string or number)
const noise = toko.openSimplexNoise('mySeed');
// or
const noise2 = toko.openSimplexNoise(42);

// Generate 2D noise
const value2D = noise.noise2D(10.5, 20.3);

// Generate 3D noise
const value3D = noise.noise3D(10.5, 20.3, 5.7);

// Generate 4D noise
const value4D = noise.noise4D(10.5, 20.3, 5.7, 2.1);

// Use in animation
for (let x = 0; x < width; x += 10) {
  for (let y = 0; y < height; y += 10) {
    const n = noise.noise2D(x * 0.01, y * 0.01);
    fill(n * 255);
    rect(x, y, 10, 10);
  }
}

Easing Functions

Toko provides a comprehensive set of easing functions for smooth animations. Each function takes a parameter t (0-1) and returns an eased value (0-1).

Basic Easing Functions

Each easing function takes a normalized time value and returns an eased value (0-1).

Parameters

  • {number} t - Input value between 0 and 1 representing progress
  • {number} [magnitude] - Optional magnitude/amplitude for Back and Elastic easing functions (default varies by function)

Returns

  • {number} - Eased output value between 0 and 1

Example

// Linear (no easing)
const linear = toko.easeLinear(0.5); // Returns 0.5

// Sine easing
const inSine = toko.easeInSine(0.5);
const outSine = toko.easeOutSine(0.5);
const inOutSine = toko.easeInOutSine(0.5);

// Quadratic easing
const inQuad = toko.easeInQuad(0.5); // Returns 0.25
const outQuad = toko.easeOutQuad(0.5);
const inOutQuad = toko.easeInOutQuad(0.5);

// Cubic easing
const inCubic = toko.easeInCubic(0.5); // Returns 0.125
const outCubic = toko.easeOutCubic(0.5);
const inOutCubic = toko.easeInOutCubic(0.5);

// Quartic easing
const inQuart = toko.easeInQuart(0.5);
const outQuart = toko.easeOutQuart(0.5);
const inOutQuart = toko.easeInOutQuart(0.5);

// Quintic easing
const inQuint = toko.easeInQuint(0.5);
const outQuint = toko.easeOutQuint(0.5);
const inOutQuint = toko.easeInOutQuint(0.5);

// Exponential easing
const inExpo = toko.easeInExpo(0.5);
const outExpo = toko.easeOutExpo(0.5);
const inOutExpo = toko.easeInOutExpo(0.5);

// Circular easing
const inCirc = toko.easeInCirc(0.5);
const outCirc = toko.easeOutCirc(0.5);
const inOutCirc = toko.easeInOutCirc(0.5);

// Back easing (with overshoot)
const inBack = toko.easeInBack(0.5);
const outBack = toko.easeOutBack(0.5);
const inOutBack = toko.easeInOutBack(0.5);
// Custom magnitude
const customBack = toko.easeInBack(0.5, 2.0);

// Elastic easing (with bounce)
const inElastic = toko.easeInElastic(0.5);
const outElastic = toko.easeOutElastic(0.5);
const inOutElastic = toko.easeInOutElastic(0.5);
// Custom magnitude (0-1)

// Bounce easing
const inBounce = toko.easeInBounce(0.5);
const outBounce = toko.easeOutBounce(0.5);
const inOutBounce = toko.easeInOutBounce(0.5);

// Extra smooth easing (Ken Perlin smoothstep)

Get Easing Function by Type

toko.getEasingFunction([easeType], [easeDirection])

Returns an easing function dynamically from type and direction constants. Useful when the easing choice comes from the parameter panel.

Parameters

  • {string} [easeType=toko.EASE_QUAD] - Easing type constant: EASE_LINEAR, EASE_SMOOTH, EASE_QUAD, EASE_CUBIC, EASE_QUART, EASE_QUINT, EASE_EXPO, EASE_CIRC, EASE_ELASTIC, EASE_BOUNCE, or EASE_BACK
  • {string} [easeDirection=toko.EASE_IN_OUT] - Direction constant: EASE_IN, EASE_OUT, or EASE_IN_OUT (ignored for EASE_LINEAR and EASE_SMOOTH)

Returns

  • {Function|null} - Easing function that takes t (0–1), or null if no matching function is found

Example

// Get easing function dynamically
const easeFunc = toko.getEasingFunction(toko.EASE_QUAD, toko.EASE_IN_OUT);
const result = easeFunc(0.5);

// Use with parameter-panel values
const ease = toko.getEasingFunction(p.easingType, p.easingDirection);

function draw() {
  const t = (frameCount % 120) / 120; // 0 to 1 over 120 frames
  const eased = ease(t);
  const x = eased * width;
  circle(x, height / 2, 50);
}

Custom Cubic Bézier Easing

Create your own easing function from cubic Bézier control points (see cubic-bezier.com to find values).

toko.cubicBezier([x1], [y1], [x2], [y2], [customName])

Creates a cubic Bézier easing function from two control points.

Parameters

  • {number} [x1=0] - X coordinate of the first control point (0–1)
  • {number} [y1=0] - Y coordinate of the first control point
  • {number} [x2=1] - X coordinate of the second control point (0–1)
  • {number} [y2=1] - Y coordinate of the second control point
  • {string} [customName=null] - Optional name for the returned function

Returns

  • {Function} - Easing function that takes t (0–1) and returns an eased value. Also exposes x1, y1, x2, y2, controlPoints, and name.

toko.cubicBezier.presets

Built-in presets that each return a ready-to-use easing function:

  • linear()
  • ease()
  • easeIn()
  • easeOut()
  • easeInOut()
  • easeInBack()
  • easeOutBack()
  • easeInOutBack()

Example

// Custom control points
const easing = toko.cubicBezier(0.25, 0.1, 0.25, 1);
const value = easing(0.5);

// Optionally give it a custom name
const named = toko.cubicBezier(0.68, -0.55, 0.27, 1.55, 'overshoot');

// Use a built-in preset
const easeInOut = toko.cubicBezier.presets.easeInOut();
const eased = easeInOut(0.3);
